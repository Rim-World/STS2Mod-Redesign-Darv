# ChangeLog 索引

本目录是版本日志分片：每个文件记录一个版本（最多 10 个小版本），七字段为「版本号 / 时间戳 / 开发人员反馈 / 实装更改概括 / 简略技术细节 / 失败经验或实验教训 / 提交编号」。源码根目录的 `CHANGELOG.md` 是按 Keep a Changelog 维护的单文件摘要，两者内容不重复。

## 版本号规则

采用语义化版本：`主版本.次版本.修订号`。玩法与选项池结构变化升主/次版本，纯修复升修订号；版本号必须同时写进 `9.SRC/DarvRelicPoolMod/DarvRelicPoolMod.json` 与游戏内可见文案，再构建打包。
