# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ①设计目的

在beta 111版本更新后，达弗偶尔会同时给出三个几乎无收益或负面效果过大的选项。

本mod设计目的有三个：

一是降低达弗同时给出三个无效选项的概率；

二是引入更多《杀戮尖塔1》中有趣且强大的Boss遗物；

三是对达弗的遗物进行分类：选项二都是加费遗物（蛇眼？）；选项三保持原版的50%尘封魔典；选项一是剩下的所有遗物。

## ②主要功能

本 mod 重新设计了先古之民达弗的三个选项（仅对原版五职业生效）。

**选项 1**：符文金字塔以 20% 概率优先判定，未命中时从星盘 / 黑星 / 空鸟笼 / 潘多拉魔盒 / 召唤铃铛 五件中均分。

**选项 2**：符文金字塔以 20% 概率优先判定（仅在选项 1 未判定到金字塔时），未命中时从添水 / 灵体外质 / 贤者之石 / 天鹅绒颈圈 / 异蛇之眼 五件中均分。

**选项 3**：尘封魔典 50% / 职业专属遗物池 50%（池内均等随机）。

符文金字塔不会同时出现在选项 1 与选项 2 中，综合出现概率约 36%。

职业专属遗物池内容如下：
- 铁甲战士：符文立方体、痛楚印记（各 25%）
- 静默猎手：悬浮风筝、袖剑（各 25%）
- 故障机器人：核能电池、机械臂（各 25%）
- 储君：先古月亮糕点、先古迷你储君、先古橙色团块（各约 16.7%）
- 亡灵契约师：先古书签、先古大帽子、先古象牙麻将牌（各约 16.7%）

铁甲战士、静默猎手、故障机器人的先古遗物均来自前作《杀戮尖塔1》。
储君/亡灵契约师的六件新的先古遗物为其六件稀有遗物的加强版本。具体效果如下：

- 先古月亮糕点：在你的回合结束时，获得 2 点星辉。
- 先古迷你储君：你每回合第一次获得和花费星辉时，获得 1 点力量。
- 先古橙色团块：在每场战斗开始时，将 3 张随机已升级的的无色牌加入你的手牌。
- 先古书签：每回合结束时，随机一张被保留的牌在本场战斗中的耗能减少 1。
- 先古大帽子：在每场战斗开始时，将 3 张随机已升级的的虚无牌加入你的手牌。
- 先古象牙麻将牌：每当你打出一张实际耗能大于等于 2 的牌时，获得 1 费。

## ③其它功能与细节

你可以在Ritsulib设置页中对mod进行设置，只能通过点击最下方的“保存并退出游戏”按钮进行保存。

①你可以单独调整某一职业的开关，关闭后该职业的达弗三个选项都将回到原版游戏的效果与概率分布。

②你可以交换铁甲战士的“痛楚印记”与故障机器人的“核能电池”，设计这一功能的原因是STS1中铁甲战士的状态牌体系在STS2中被移植给了故障机器人。

③你可以单独设置“异蛇之眼”是否会出现在某个职业的达弗选项 2 ，设计这一功能的原因是显然异蛇之眼非常不适合储君，他的高费牌更多体现在消耗辉星而非单纯费用高。

**互斥规则**：对于储君和亡灵契约师职业，当玩家已持有某件稀有遗物时，达弗的选项 3 不再出现对应的先古版本；反之，获得先古版本后，本局内对应的稀有遗物将不会再从宝箱、商店、战斗掉落与事件中重复出现。

若玩家持有全部三件稀有遗物，则达弗选项 3 为 100% 尘封魔典。（几乎不可能出现这种情况）

## ④ 影响（基于本人游戏理解）

提升符文金字塔的出现概率至36%，107原版中该概率为31.25%，111原版中该概率约为25%；

原本添水、灵体外质只会在第二幕出现，现在其可能在第三幕出现，大幅减少了其负面效果；

移植自STS1的6件先古遗物在STS2环境中表现大多显著强于STS1，新设计的6件先古遗物也有极强通用性，不可能再出现三个无效选项。

达弗可能依然算不上最强大的先古之民，但现在他至少达到了先古之民的平均水平。

本 mod 影响存档：不影响过去的游戏记录；在新的游戏记录中，关闭 mod 后本mod添加的先古遗物不再可用，游戏记录会按游戏机制处理。

## ⑤ 语言、环境与版本

本mod仅支持中文（zhs、zht）和英文（eng），其余语言显示英文。

本 mod 依赖基础 mod：RitsuLib（最低版本0.5.14）。

本 mod 支持 default 0.107.x 与 public beta 0.111.0 及以上版本（两版本存在虚方法签名差异的接口，通过可选补丁 + 反射自动适配，效果相同）。

理论上只要没有大的 API 更新或游戏内容修改，本 mod 无须修改即可自动适配新版本。

## ⑥ 实现方式与兼容性

本 mod 基于 RitsuLib patcher 框架（Harmony 补丁）实现：替换达弗选项生成逻辑、图鉴子分类的枚举与展示、设置页与保存功能。

六件STS1遗物美术素材经裁剪处理以适应STS2程度；六件自制先古遗物复用官方素材。

兼容问题：联机兼容性未经仔细测试；非现有原版五职业（mod 角色和未来的新角色）自动回退到原版达弗逻辑。

本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。
