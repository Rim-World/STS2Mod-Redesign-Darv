## 1. 现象与根因

| 现象 | 根因 |
|---|---|
| 遗物图鉴整页空白，只剩背景和返回按钮 | `Darv.AllPossibleOptions` 枚举时抛 `MissingMethodException`，`NRelicCollection.LoadRelics` 中断，七个分类停留在透明状态 |
| `Loadout` 面板条目缺失 | 同一异常发生在 `LoadoutBag.BuildRelicGroupingData`，`TryInitializeLoadoutItems` 捕获后不再重试 |
| 先古遗物图标镜像时好时坏 | `NRelicMirrorPatcher` 在 `_Ready` 读取未赋值的 `NRelic.Model`，抛 `InvalidOperationException`，补丁内捕获后跳过镜像 |

v0.113 删除 `AncientEventModel.RelicOption(RelicModel, string, string)`，只保留两参重载。v1.0.0 在 v0.111 编译，`RelicOption(relic)` 的可选参数在调用点展开为三参调用，绑定到已删除的方法。

`DarvAllPossibleOptions.Build` 是 `yield` 迭代器。Prefix 只把迭代器对象赋给 `__result`，方法体没有执行；真正枚举发生在图鉴或 Loadout，已经在 Prefix 的 `try/catch` 之外，所以原补丁的异常回退没有生效。

## 2. 修复内容

### 2.1 `RelicOptionCompat`

新增反射垫片，按运行时存在的重载调用：

- 0.107 / 0.111：`RelicOption(RelicModel, string, string)`，参数 `(relic, "INITIAL", null)`。
- 0.113：`RelicOption(RelicModel, string)`，参数 `(relic, "INITIAL")`。

5 处调用全部替换：

- `DarvAllPossibleOptions.Build`
- `DarvOptionPool.MakeRelicOption`
- `DarvOptionPool.MakeDustyTomeOption`
- `VanillaFallbackPool.Generate`（两处）

### 2.2 `AllPossibleOptions` 立即枚举

`DarvAllPossibleOptionsPatcher.Prefix` 改为：

```csharp
__result = DarvAllPossibleOptions.Build(__instance).ToList();
```

迭代器在当前 `try/catch` 内执行。未来再出现异常时，Prefix 可以真正返回 `true` 回退原版。

### 2.3 镜像补丁生命周期

`NRelicMirrorPatcher` 改为双入口：保留 `NRelic._Ready`，同时增加 `NRelic.Reload`：

- `_Ready` 保留原有“节点就绪后”的最终时序；`Reload` 覆盖 `Model` setter 的晚赋值路径。
- 113 源码中 `NRelic._Ready()` 末尾调用 `Reload()`；`Model` setter 在赋值后也调用 `Reload()`。两条路径都覆盖。
- `TryGetModel` 捕获 `Model` 未赋值时的 `InvalidOperationException`；模型就绪后 setter 再次触发 `Reload`，补上镜像。
- `ApplyMirror` 设置绝对 `Scale = (-1, 1)`，两个入口重复触发幂等。

### 2.4 图鉴光效安全读取

`RelicCollectionOutlinePatcher` 在读取 `n.Model` 前捕获 `InvalidOperationException`，模型未就绪时跳过本条目，不再刷错误日志。113 的 `NRelicCollectionEntry._Ready` 通过 `NRelic.Create` 先赋值 Model 再 `AddChild`，正常图鉴路径不会触发跳过；该分支只防御其他创建路径。
