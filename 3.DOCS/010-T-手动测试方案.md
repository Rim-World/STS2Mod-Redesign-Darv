# 010-T 手动测试方案

> 2026-08-23。测试由用户手动执行；**测试期间请勿让我启动游戏**。
> Mod：DarvRelicPoolMod v0.1.0（已安装至 游戏 `mods/DarvRelicPoolMod/`，依赖工作坊 STS2-RitsuLib 0.5.14）。
> 游戏控制台命令（游戏内 DevConsole，用于强制进入事件）：
> - `ancient DARV` —— 强制进入达弗事件（随机三选项）
> - `ancient DARV <遗物关键字>` —— 进入并把**第 1 个选项**强制为指定遗物（关键字匹配 TextKey 包含；如 `ancient DARV ASTROLABE`）

## 1. 三槽位分布验证（核心，约 30 分钟）

方法：开局（任意职业）→ 控制台 `ancient DARV` 强制进入 → 记录 3 个选项 → 选择任意一个离开 → 再 `ancient DARV` 重复。**每次进入都会重新生成**（同局同 seed 会复现同一序列——注意：同一局内多次进入选项序列相同是**预期行为**！要统计分布请用不同局或不同角色测试）。

### 1.1 槽位 1（五选一，各 20%）
- 记录 50 次进入的槽位 1 遗物：星盘 / 潘多拉魔盒 / 黑星 / 召唤铃铛 / 空鸟笼
- 预期：五个都出现，各约 10 次（±8）；**不会**出现槽位 2/3 的遗物

### 1.2 槽位 2（五选一，各 20%）
- 记录 50 次的槽位 2：添水 / 灵体外质 / 贤者之石 / 天鹅绒颈圈 / 异蛇之眼
- 预期：同上；**不会**出现槽位 1/3 的遗物

### 1.3 槽位 3（50/50，2026-08-25 v2.2 起）
- 记录 100 次的槽位 3（铁甲战士）：尘封魔典 ≈50 次、符文立方体+痛楚印记 合计 ≈50 次（两者各 ≈25）
- 用静默猎手：悬浮风筝+袖剑 各 ≈25；故障机器人：核能电池+机械臂 各 ≈25
- 用储君：三件先古（先古月亮糕点/先古迷你储君/先古橙色团块）各 ≈16.7%（未持有稀有版时）；持有某稀有版 → 对应先古件不再出现；三件稀有全持有 → 100% 魔典
- 用亡灵契约师：三件先古（先古书签/先古大帽子/先古象牙麻将牌）同理
- 尘封魔典出现时：选项上显示"尘封魔典"，且**按角色发放不同先古卡**（铁甲战士 vs 静默猎手看到的描述卡不同）

### 1.3b 符文金字塔（v2.2 起移入选项 1/2）
- 统计 100 次：金字塔出现在选项1 ≈20 次、选项2 ≈16 次（选项1 未命中时再判定）、**不会同时出现在选项1 和选项2**
- 金字塔未占用时：选项1/2 各五件（或蛇眼关闭时四件）均分
- 选项3 **永不再出现**符文金字塔

### 1.4 位置语义
- 确认选项**顺序固定**：槽位 1 永远在第 1 个、槽位 2 永远在第 2 个、槽位 3 永远在第 3 个（不会出现槽位 2 跑到第 1 位的情况）

## 3. 设置开关验证（约 20 分钟）

### 3.1 职业关闭 → 回退原版
1. 设置页关闭"铁甲战士"，保存（或直接新开一局——设置**新局生效**）
2. 铁甲战士开局，`ancient DARV` 多次
3. 预期：选项为**原版 111 逻辑**（11 组池：第 2 幕 Ectoplasm/Sozu/贤者之石/天鹅绒颈圈可出、3 选项为"洗牌取前 2/3"而非固定槽位、出现 2 个随机+魔典或 3 个随机）
4. 其余职业（静默猎手等）不受影响，仍为新逻辑（**设置互不影响**）

### 3.2 当前局不生效（v4 恢复：未保存的改动对当前局无效）
1. 开局（储君）后，**游戏中**打开设置页关闭"储君"职业开关（**不点保存**）
2. 本局内 `ancient DARV` → 仍为**新逻辑**（改动未保存、未生效，达弗按磁盘值生成）
3. 退出设置界面再重进 → 开关显示**修改前状态**（亮的）；本局仍按新逻辑
4. 点"保存并退出" → 重启后储君达弗才变为原版逻辑

### 3.3 交换开关
1. 开启"交换痛楚印记与核能电池"（保存）
2. 新局铁甲战士：槽位 3 的 20% 池 = 符文立方体 + **核能电池**（痛楚印记不再出现）
3. 新局故障机器人：槽位 3 的 20% 池 = **痛楚印记** + 机械臂（核能电池不再出现）
4. 关闭开关后恢复

### 3.4 保存并退出
1. 修改任意设置 → 点击"保存并退出游戏"按钮
2. 预期：按钮文案有说明（保存将自动退出）；点击后游戏**自动退出**（无报错）
3. 重启游戏，设置保持已修改状态

### 3.6 保存语义（2026-08-25 v4：未保存的改动不生效、不保留；落盘仅"保存并退出"）
1. 页面**顶部**出现"保存须知"提示（"必须点击本页面最下方的「保存并退出游戏」按钮才能保存设置，否则mod设置将不会保存。"，中英繁三语自动切换）；页面**底部**保存按钮旁也有提示
2. 修改任意开关（观察：点击后开关**不弹回**，显示改动值）
3. **不点保存，直接在本局用控制台 `ancient DARV`** → 选项分布**不变**（未保存的改动不生效，达弗按磁盘值生成）
4. **退出设置界面后重新进入（不重启游戏）** → 开关显示**修改前状态**（未保存改动被丢弃，UI 与生效值一致）
5. 再次修改开关 → **不点保存，直接重启游戏** → 设置页显示**原值**（未保存的改动不落盘）
6. 修改开关 → 点"保存并退出" → 游戏自动退出 → 重开游戏 → 设置页显示改动值（已保存），达弗按新设置生成（无需等新局）
7. 边界：只改一个开关点保存，其余开关保持原值（未改动的项不被覆盖）

### 3.5 设置持久化
- 修改 → 退出游戏（任意方式）→ 重启 → 设置保持

### 3.7 蛇眼角色开关（2026-08-25 v3：两行布局——职业名在上、官方按钮在下；保存语义同 §3.6）
1. 设置页出现"异蛇之眼是否在该职业的第二个选项中出现，默认开启"section（三语）：**第一行五个职业名**（与下方按钮列对齐、居中），**第二行五个 ritsulib 官方按钮**（无文字，选中态=开启，默认全部选中）
2. 点击"储君"按钮（变未按下=关闭，**不点保存**）→ 本局储君 `ancient DARV` 多次：槽位2 **仍可出现异蛇之眼**（未保存不生效）；退出设置界面重进 → 按钮回到**按下态**（修改前状态）
3. 点"保存并退出" → 重启 → 储君 `ancient DARV`：槽位2 **永不出现异蛇之眼**，其余四件（添水/灵体外质/贤者之石/天鹅绒颈圈）各约 25%；其他职业按钮不受影响（仍按下）
4. 组合：关闭"储君"职业开关（回退原版）+ 关闭储君蛇眼 → 槽位2 仍按原版五选一（含异蛇之眼）——蛇眼开关在职业回退时不生效
5. 按钮视觉与三语职业名随游戏语言切换（重进设置界面后生效）
